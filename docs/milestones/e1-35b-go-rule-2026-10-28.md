# E1 35B launch rule (GO / NO-GO from E1-small)

**Decision note, PI decision of 2026-10-28 (≈ 19:00 CET), written
2026-10-28 19:10 CET.** At the time of writing **no E1-small result
exists**: the E1-small pre-registration is frozen
(`docs/osf-prereg-e1-small-2026-10-25.md`, SHA-256
`6d47d8b71829d884d3a18dda84cd21aa080f1090101d62a4bafe6bc493208463`,
filing package at `963bb24`), it is not yet filed on OSF, and no
tuning or confirmatory cell of it has run. This rule is fixed before
the E1-small run starts and is not changed after any E1-small number
is seen. It decides only whether the 35B study
(`docs/osf-prereg-e1-replay-controls-2026-10-23.md`, PR #41) is
launched; it changes nothing in either pre-registration and is not a
hypothesis test of its own.

## Inputs

The rule reads only the **confirmatory states** of the three E1-small
hypotheses (E1-small §2), as written by the registered decision code
(`scripts/analyze_e1_cuda.py`, field `states`, with `run_complete` and
`confirmatory`) on the E1-small confirmatory cells of the registered
instrument (E1-small §9.2):

- H14-A (`p_min` vs `p_ctrl_template`) and H14-B (`p_equ` vs
  `p_ctrl_vanilla_replay_tuned`): one of UNINTERPRETABLE, SUPERIOR,
  POSITIVE-BELOW-SESOI, BOUNDED-NO-GAIN, INCONCLUSIVE.
- H14-C (`p_equ` vs `p_ctrl_onpolicy_replay`): one of UNINTERPRETABLE,
  NON-INFERIOR, INFERIOR, INCONCLUSIVE, or INFEASIBLE if the tuning
  amendment declared it so (E1-small §5.4).

Secondary contrasts, the exploratory arm (`p_ctrl_lr_matched`), the
joint headline (§7), per-source descriptions, diagnostics, the
pipeline smoke and any exploratory reading never enter the rule.

## Rule (first matching line)

1. **POSTPONE** if the E1-small run is not confirmatory: fewer than 141
   complete seeds (`run_complete` false, E1-small §4 / §8), or cells not
   from the registered instrument. E1-small is then reported as
   exploratory, as its §8 prescribes.
2. **POSTPONE** if any of H14-A, H14-B, H14-C is UNINTERPRETABLE (a
   validity gate of E1-small §4 / §6 failed).
3. **GO** if H14-A or H14-B (at least one) is **SUPERIOR** or
   **POSITIVE-BELOW-SESOI**. Both states have `L > 0`, i.e. the
   registered one-sided paired superiority test rejects μ ≤ 0 at
   α = 1/60 (E1-small §2); these are the "non-null decided states" of
   the PI's rule. H14-C does not trigger GO: its confirmatory state
   NON-INFERIOR bounds `p_equ` below OPR by less than δ and does not
   establish a non-zero effect.
4. **POSTPONE** otherwise, i.e. both H14-A and H14-B are BOUNDED-NO-GAIN
   or INCONCLUSIVE (whatever H14-C is, including INFEASIBLE). E1-small is
   then reported as a null at 4B in the sense of its §2 and §7: a
   BOUNDED-NO-GAIN state bounds the gain below δ = 0.01; an INCONCLUSIVE
   state is "no claim either way" and is not read as absence.

GO means the 35B study may proceed to its filing gate and run on the
hardware the PI chose (2026-10-28: a rented single GB300, CUDA /
PyTorch path, protocol as written; the MLX port is kept in reserve).
POSTPONE means the 35B is not launched on the strength of E1-small;
any later launch needs a new dated PI decision.

## Interpretation choices for the PI (stated, not silently made)

- Line 2 reads "an UNINTERPRETABLE E1-small also postpones" as **any**
  of the three hypotheses being UNINTERPRETABLE, even if another one
  would satisfy line 3. The alternative (postpone only when every
  hypothesis that could trigger GO is UNINTERPRETABLE) would let a
  single valid SUPERIOR launch the 35B.
- Line 3 counts POSITIVE-BELOW-SESOI ("positive, with an estimate below
  δ; reported, no claim", E1-small §7) as non-null, because its
  superiority test rejects; a stricter rule would count SUPERIOR only.
- Line 3 excludes H14-C NON-INFERIOR from triggering GO.
